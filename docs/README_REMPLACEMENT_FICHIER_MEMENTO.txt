-===========================================================================
   PROCÉDURE DE MISE À JOUR DU FICHIER MEMENTO (À LIRE IMPÉRATIVEMENT)
===========================================================================

ATTENTION : Ne supprimez JAMAIS l'ancien fichier PDF pour en importer un nouveau.
Si vous faites cela, l'ID du fichier changera et le lien de téléchargement automatique utilisé par l'agent IA sera définitivement CASSÉ.

Pour mettre à jour le fichier Memento (changement de version, correction, etc.) tout en conservant scrupuleusement le même ID et le même lien, suivez pas à pas la procédure ci-dessous, issue de l'image_2578c4.png :

---------------------------------------------------------------------------
ÉTAPES POUR REMPLACER LE FICHIER SANS CASSER LE LIEN :
---------------------------------------------------------------------------

1. Faites un CLIC DROIT sur le fichier PDF actuel du Memento dans Google Drive.

2. Dans le premier menu de gauche qui apparaît, passez votre souris sur l'onglet :
   "Informations sur le fichier" (situé juste en dessous d'"Organiser").

3. Un sous-menu va alors s'ouvrir sur votre droite. Dans ce nouveau sous-menu, cliquez sur :
   "Gérer les versions".

4. Une petite fenêtre va apparaître au centre de votre écran. Cliquez sur le bouton :
   "Importer une nouvelle version" pour y déposer votre nouveau PDF mis à jour.

---------------------------------------------------------------------------
RÉSULTAT :
---------------------------------------------------------------------------
En suivant cette méthode, le fichier se met à jour instantanément dans le Drive, et l'ID dans l'URL reste inchangé pour notre agent IA. L'automatisation continuera de fonctionner de manière transparente avec la nouvelle version du document !
